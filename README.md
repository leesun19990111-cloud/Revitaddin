# Sunny Tools (WallSplitter)

Revit용 실무 편의 애드인 모음입니다. Revit 리본에 전용 탭 **"Sunny Tools"**를 추가하며, **Revit 2023 ~ 2027**을 하나의 소스로 지원합니다.

## 주요 기능

### 벽체 분리 / 바닥 분리
복합 구조(여러 레이어)로 이루어진 벽체·바닥을 레이어별 단일 재질 벽체·바닥으로 분리합니다.
- 선택한 벽/바닥의 각 레이어(멤브레인 제외)를 별도의 요소로 생성하고, 원본은 삭제합니다.
- 직선/호(Arc) 형태의 벽 위치선, 편집된 프로파일(스케치)도 그대로 복사됩니다.
- 분리 후 같은 재질끼리는 자동으로 코너 트림 및 재결합됩니다.
- 유형 이름은 두 가지 방식으로 지정할 수 있습니다.
  - **템플릿 방식**: 프로젝트명/건물명/커스텀 텍스트 + 재질명/두께를 조합한 규칙으로 자동 생성
  - **직접 지정 방식**: 레이어마다 기존 유형을 직접 검색/선택 (선택 내용은 "단일/복수" 설정에 따라 세션 동안 재사용 가능)

### NAMER (이름 일괄 변경)
뷰/시트/패밀리/유형/범례/일람표/재료/뷰 템플릿 이름을 필터링 후 일괄 변경하는 도구입니다.
- 포함/불포함/일치/불일치/시작함/끝남 등 다양한 필터 모드
- 문자열 치환, 위치 삽입, 구분자 기준 자리바꾸기, 구간 삭제 등 4가지 변경 방식
- 적용 → 최종 적용의 2단계 구조로, 여러 작업을 이어서 누적 적용 후 한 번에 모델에 반영
- **창을 띄워 둔 채 Revit에서 계속 작업할 수 있습니다** (모드리스). 닫지 않아도 모델을 편집하거나 뷰를 옮겨 다닐 수 있고, "최종 적용"을 눌러도 창은 닫히지 않습니다.
- **기존 이름을 더블클릭하면 그 항목 하나만 바로 수정**할 수 있습니다 (Enter 확정 / Esc 취소 / 다른 곳을 클릭해도 확정). 일괄 작업과 똑같이 "최종 적용"을 눌러야 모델에 저장됩니다.
- **이름 위에 마우스를 올리면 오른쪽 끝에 "특성" 버튼**이 나타나, **Revit 기본 창**으로 그 항목을 엽니다 — 유형/패밀리는 Revit의 "유형 특성" 창, 뷰/시트/범례/일람표는 그 뷰를 열어 Revit 특성 팔레트에 표시, 뷰 템플릿은 "뷰 템플릿" 창, 재료는 "재료 탐색기"입니다(뒤의 둘은 Revit API 제약으로 창까지만 열리고 목록에서 직접 골라야 합니다). 누르면 Revit의 선택과 활성 뷰가 바뀝니다.
- 유형/패밀리를 쓰는 부재가 모델에 하나도 없으면 Revit 유형 특성 창을 열 수 없어(그 명령은 "선택된 부재"를 기준으로 동작합니다), 그때만 Sunny Tools의 간단한 특성 창이 대신 열립니다.
- "적용"을 눌러도 **"더 보기"로 펼쳐 둔 분량과 스크롤 위치가 그대로 유지**되므로, 목록을 한참 내려놓고 작업하다가 매번 처음부터 다시 펼칠 필요가 없습니다.

### 재료 지정 (Material Assign)
여러 패밀리/유형에 재료를 일괄 지정, 재료 삭제(사용처 자동 재지정), 재료의 클래스/설명 일괄 변경을 지원합니다.
- 레이어가 여러 개인 벽/바닥, 재료 파라미터가 여러 개인 문/창처럼 재료를 동시에 여러 개 쓰는 유형도 레이어/파라미터별로 각각 지정할 수 있습니다.

### 모델간 변경 반영 (구 "모델 동기화")
NAMER/재료 지정에서 최종 적용한 변경사항을 다른 중앙모델에도 그대로 재현합니다.
- 최종 적용될 때마다 자동으로 변경 기록에 누적되며, 이름이 같은 대상을 다른 문서에서 찾아 다시 적용합니다.
- 이름이 정확히 하나만 일치하면 자동 적용되고, 0개나 여러 개면 직접 고르는 창이 뜹니다 (재료 삭제는 안전을 위해 대상이 없으면 그냥 건너뜁니다).
- 변경사항을 파일로 내보내/가져오거나, 같은 세션에 열려 있는 다른 문서에 바로 적용할 수 있습니다.

### 패턴 스튜디오
Revit의 기존 채우기 패턴 또는 `.PAT` 파일을 독립 편집 창에서 불러와 수정한 뒤 Revit 패턴이나 PAT 파일로 저장합니다.
- 전체 패턴을 원하는 각도로 직접 입력해 회전할 수 있고, 전체 스케일과 폭·높이를 서로 독립적으로 조절할 수 있습니다.
- 패턴을 이루는 각 선군마다 회전·크기·간격 값을 따로 저장하고 조절합니다. 다른 선군을 선택해도 앞 선군의 편집값이 옮겨가지 않습니다.
- 미리보기는 유한한 선 그림을 돌리는 방식이 아니라 Revit과 같은 무한 반복 정의를 매번 다시 그리므로, 회전 뒤 모서리도 같은 패턴으로 자동 채워집니다.
- Revit 내부 각도 단위와 편집기의 도 단위를 정확히 변환해, 패턴을 선택한 직후 0°·100% 상태에서는 원본 방향과 배열을 그대로 보여줍니다.
- 기존 Revit 패턴의 선·공백 교대 순서를 정확히 복원해 HEX·원형 근사·끊긴 선 패턴을 긴 실선 격자로 바꾸지 않습니다. 점과 각 짧은 선의 원래 길이도 유지합니다.
- 기본 저장 방식은 원본을 유지하는 새 패턴 생성입니다. 원본 덮어쓰기는 Revit에서 불러온 패턴에만 허용하며, 모든 사용처가 함께 바뀐다는 경고와 재확인을 거칩니다.
- 하나의 PAT 파일에 여러 패턴이 있으면 모두 불러올 수 있고, 현재 편집 결과는 패턴 하나당 별도 PAT 파일로 내보냅니다. `;%TYPE=MODEL`을 패턴 이름 줄보다 앞에 한 번만 선언한 PAT 파일도 그 선언을 파일 전체의 기본 패턴 종류로 인식합니다.

### 모델선 패턴 캡처
CAD 링크를 Revit에서 스냅해 따라 그린 모델선 또는 상세선을 한 단위 패턴으로 가져와 패턴 스튜디오에서 확인·저장합니다.
- 평면·천장평면·입면·단면에서 **첫 모서리 → 첫 변의 끝 → 둘째 변의 끝**을 ㄱ자 순서로 지정합니다. 첫째→둘째가 가로축, 둘째→셋째가 높이가 되며 세 번째 점의 어긋남은 직교 투영해 회전 가능한 사각형 반복 틀을 완성합니다.
- 시작할 때 모델 패턴(실제 크기)과 제도 패턴(현재 뷰 축척 적용) 중 하나를 고릅니다. 세 점을 찍으려면 현재 뷰와 평행한 작업 기준면이 먼저 설정되어 있어야 합니다.
- 점을 지정할 때 Revit 기본 끝점·중간점·교차점·근처점·원 중심·사분점·직교 스냅을 사용하므로 커서 옆 스냅 표식도 Revit과 동일하게 표시됩니다.
- 반복 틀 안과 경계에 걸친 모델선·상세선·호·원을 현재 화면 평면에 투영해 수집하고, 경계를 넘어간 선은 반대편으로 자동 연결해 반복 패턴으로 만듭니다. Revit 채우기 패턴의 형식상 호·원은 짧은 직선 선군의 근사 형태로 저장됩니다.
- 모델 패턴은 실제 치수 1:1, 제도 패턴은 현재 뷰 축척으로 나눈 종이상 크기로 저장합니다.

### 패턴 타공 / 타공 복원
벽·바닥·천장·커튼월 패널의 재료 표면 패턴에서 사용자가 직접 고른 닫힌 영역만 완전 관통 타공합니다.
- 패턴이 보이는 평면·천장평면·입면·단면 2D 뷰에서 여러 면을 고릅니다. 제도 패턴은 현재 시선에 거의 정면인 넓은 재료면을 선택하며, 끝면·상하면·리빌면을 잘못 고르면 대상 이름과 정면 이탈각을 안내합니다. 표면 전경 패턴을 우선 사용하고, 없으면 표면 배경 패턴을 사용합니다. 한 번에 고른 면은 같은 패턴이어야 합니다.
- 패턴 정의의 임의 원점을 사용하는 대신 Revit이 현재 면에 실제로 표시한 패턴 선을 읽으므로, 면에서 정렬·이동된 모델 패턴의 위치도 그대로 반영합니다. 로드 가능한 커튼패널은 패밀리 내부 좌표의 면을 프로젝트 위치로 복원하고, 패턴선 포함/제외 화면 결과의 차이로 패널 외곽선과 재료 패턴선을 구분합니다.
- 독립 창은 대상 면에 실제로 표시된 폐영역을 그대로 보여줍니다. 뚫을 영역을 하나씩 클릭하고 다시 클릭해 해제하며, 다른 반복 영역으로 자동 확장하지 않습니다. 여러 면을 선택한 경우 면 목록을 바꿔가며 각 면의 영역을 따로 고릅니다. 경계에 걸린 영역은 호스트 경계에 맞춰 잘린 모양 그대로 타공하며, 최소 폭·높이 조건은 최종 잘린 구멍 크기에 적용됩니다.
- 실행 전 남는 재료가 여러 조각으로 분리되는지, Revit 최소 선 길이를 어기는지, 실제 스케치가 생성 가능한지를 대상별로 검사합니다. 한 대상이 실패해도 다른 대상은 계속 처리하고 결과를 따로 알립니다.
- 벽·바닥·천장은 기존 프로파일/스케치를 보존하며 타공 경계를 추가합니다. 로드 가능한 커튼패널은 원본 패밀리를 변경하지 않고 선택 패널 전용 복제 패밀리에 관통 보이드를 만듭니다. 단순 평면 시스템 커튼패널은 현재 패널 형상·두께·재료를 검증한 뒤 고정형 로드 패밀리로 안전하게 대체해 타공하며, 비정형 패널이나 필요한 커튼패널 템플릿이 없는 PC에서는 변경하지 않고 사유를 알립니다.
- `타공 복원`은 선택한 호스트에서 가장 최근 Sunny Tools 타공 1회를 되돌립니다. 타공 뒤 프로파일이 다른 작업으로 바뀌었으면 자동 덮어쓰지 않고 중단합니다.

### 커스텀 버튼 (구 "빠른 토글")
현재 뷰에서 미리 지정해 둔 뷰템플릿/필터/작업세트를 딸깍 한 번으로 켜고 끌 수 있는 커스텀 툴바를 Revit 창 상단에 표시합니다.
- Revit 자체 신속접근 도구모음(QAT)에는 API로 버튼을 추가할 수 없어, 대신 Revit 창을 따라다니는 별도 플로팅 창으로 제공됩니다.
- 같은 종류(뷰템플릿/필터/작업세트)라도 이름을 다르게 지정해 여러 버튼을 등록할 수 있고, 버튼이 많아지면 툴바 자체가 옆으로 늘어납니다.
- **링크된 요소 버튼**: 지금 보고 있는 뷰에 걸린 링크를 **종류에 상관없이 전부** 딸깍 한 번으로 끄고 켭니다 — 링크된 CAD 도면, Revit 모델, IFC, 지형(지형솔리드) 링크, DWF 마크업, 포인트 클라우드, 외부 좌표 모델이 모두 대상입니다. 설정 창에서 따로 고를 대상이 없고, 링크가 하나도 없는 뷰에서는 회색(비활성)으로 표시됩니다. Revit의 가시성/그래픽 설정에서 해당 카테고리들을 끄고 켜는 것과 같은 동작이라 V/G 대화상자에서도 그대로 확인·복구할 수 있습니다. 다만 아래 "링크된 모델 버튼"의 목록에서 링크 하나만 따로 꺼 둔 경우, 이 버튼으로 전체를 켜도 그 링크는 꺼진 채로 남습니다.
- **링크된 도면 버튼**: 지금 보고 있는 뷰에 링크된 CAD 도면을 딸깍 한 번으로 끄고 켭니다. 설정 창에서 따로 고를 대상이 없습니다 — 버튼만 추가해 두면 활성 뷰에 링크된 도면이 있을 때 저절로 켜진 상태로 활성화되고, 누르면 그 뷰에서 도면이 사라집니다(다시 누르면 돌아옵니다). 링크된 도면이 없는 뷰에서는 회색(비활성)으로 표시됩니다. Revit의 가시성/그래픽 설정에서 "가져온 카테고리"를 끄고 켜는 것과 같은 동작이라 V/G 대화상자에서도 그대로 확인·복구할 수 있습니다. 도면을 링크가 아니라 "가져오기"로 넣은 경우는 대상이 아닙니다.
- **링크된 모델 버튼**: 누르면 지금 보고 있는 뷰에 링크된 Revit 모델 목록이 열리고, **링크를 하나씩** 눌러 끄고 켤 수 있습니다(맨 위의 "전체 켜기"/"전체 끄기"로 한 번에 처리할 수도 있습니다). 링크된 모델은 Revit이 링크마다 카테고리를 나누지 않기 때문에 도면과 달리 목록에서 고르는 방식이며, 끄고 켜는 결과는 V/G 대화상자의 "Revit 링크" 탭에서 링크별 표시 체크박스를 켜고 끄는 것과 같습니다. 링크된 모델이 없는 뷰에서는 버튼이 회색(비활성)으로 표시되고, 버튼 색은 그 뷰에 보이는 링크가 하나라도 있는지를 알려줍니다. 링크된 모델 안에 다시 걸려 있는 링크(중첩 링크)는 부모 링크를 끄면 같이 꺼지므로 목록에 따로 나오지 않습니다.
- **색상 버튼**: 다른 버튼들과 달리 켜고 끄는 방식이 아니라, 클릭하면 색상 팔레트와 투명도 슬라이더가 담긴 작은 패널이 버튼 위치(화면 하단에 가까우면 위쪽, 아니면 아래쪽)에 펼쳐집니다. 설정 창에서 미리 어떤 모델 카테고리에 적용할지만 골라두면, 패널에서 색상을 클릭하거나 슬라이더를 움직일 때마다 활성 뷰의 그 카테고리에 실시간으로 반영됩니다(예: 협의용으로 특정 부재를 빨갛게 강조하거나 배경 요소를 반투명하게). 패널의 "재지정 지우기" 버튼을 누르면 이 카테고리에 걸린 색상/투명도 등 그래픽 재정의를 전부 지워 원래 모습으로 되돌립니다. 기본값이 "작은 버튼"이라 작은 아이콘 + 두 줄까지 줄바꿈되는 라벨이 나란히 놓이는 Revit 리본의 "작은 버튼" 스타일로 그려지고, 작은 버튼끼리는 한 줄로 계속 늘어나지 않고 2단으로 쌓입니다(설정 창에서 "큰 버튼"으로 바꿀 수 있습니다).
- **층별 단면상자 버튼**: 설정 창에서 **아래 레벨과 위 레벨을 하나씩** 골라 두면, 버튼을 누를 때마다 그 두 레벨 사이만 남기고 잘라 보는 **3D 뷰를 만들어 그 뷰로 이동**합니다(예: 1층~3층). 같은 조합으로 다시 누르면 이미 만들어 둔 뷰를 재사용하고 범위만 다시 맞추므로 뷰가 쌓이지 않습니다. 가로(평면) 범위는 모델 전체를 감싸도록 매번 다시 계산하며, 위/아래를 반대로 골라도 높이를 비교해 알아서 정렬합니다.
  - **다른 프로젝트에서도 같은 층을 알아서 찾습니다** — 설정은 이 PC에 하나로 저장되는데 모델마다 레벨 이름 규칙이 다르므로, **버튼을 만들 때 고른 레벨의 높이와 가장 가까운 레벨**을 먼저 찾고, 높이가 거의 같은 후보가 여럿일 때만 이름과 층 번호(`1층`=`1F`=`Level 1`=`L1`=`01F`=`GF`, `지하1층`=`B1`=`B1F`=`Basement 1`)를 참고해 그중 하나를 고릅니다(층 높이가 달라도 "그 높이에 가장 가까운 층"으로 붙으므로 이름이 전혀 다른 모델에서도 대개 맞습니다). 다른 이름으로 맞춰졌을 때는 설정 창이 "이 프로젝트에서는 'L1 ~ L2'로 자동으로 맞춥니다"라고 알려 주고, 만들어지는 3D 뷰 이름도 실제로 잘린 레벨 이름을 씁니다. 높이를 기억하기 전(v71 이전)에 만든 버튼은 설정 창을 한 번 열면 지금 모델의 같은 이름 레벨에서 높이를 채워 넣습니다.
- **기능 버튼**: 뷰의 상태를 켜고 끄는 게 아니라, 클릭하면 다른 Sunny Tools 기능(재료 지정, NAMER, 모델간 변경 반영, 패턴 스튜디오·모델선 캡처·패턴 타공·타공 복원, 경고Pick 등 리본에 있는 기능 전부)이나 Revit 기본 기능(공동작업탭의 "중앙 모델과 동기화" 등)을 즉시 한 번 실행합니다. 설정 창에서 검색으로 원하는 기능을 찾아 등록합니다 — Sunny Tools 자체 기능은 목록에 항상 나오고, Revit 기본 기능은 개수가 매우 많아 검색어를 입력해야 나타납니다. Revit 기본 기능은 한글과 영문 어느 쪽으로 검색해도 찾을 수 있으며, 검색 결과·현재 선택·툴팁의 기능 이름은 현재 실행 중인 Revit의 표시 언어(한국어/영어)를 따릅니다.
- 오른쪽 편집 영역의 **③ 대상** 위 설명은 한 줄로 접혀 있고 "자세히"를 누르면 펼쳐집니다 — 설명이 길어서 정작 고르는 목록이 좁아지는 일이 없도록 한 것입니다(한 번 펼치면 창을 닫을 때까지 계속 펼쳐져 있습니다).
- **설정 창**: 맨 위에 **툴바 미리보기** 띠가 있어, 저장하기 전에도 실제 커스텀 버튼바가 어떤 모습이 될지 그대로 확인할 수 있습니다 — 드래그 손잡이, 작은 버튼이 2단으로 묶이는 모양, 우측 끝에 늘 붙는 설정(톱니바퀴) 버튼까지 실제 툴바와 같은 규칙으로 그립니다. 미리보기의 버튼을 클릭하면 바로 그 버튼을 편집하고, **끌어서 놓으면 순서가 바뀝니다**(끄는 동안 어디에 놓일지 표시선이 나타납니다). 아래는 왼쪽 "등록된 버튼" 목록과 오른쪽 **① 이름 → ② 모양 → ③ 대상** 단계형 편집 영역으로 나뉩니다. 대상을 하나도 고르지 않은 버튼은 목록과 편집 화면에 "대상 미지정"으로 표시됩니다(그 상태로 두면 툴바에서 회색으로 눌리지 않습니다).
- **순서는 미리보기에서 끌어서 바꿉니다** — 왼쪽으로 끌면 앞으로, 오른쪽으로 끌면 뒤로 갑니다. 등록된 버튼 목록에는 순서를 바꾸는 화살표가 없습니다. 버튼이 많아 미리보기가 넘칠 때는 **미리보기 위에서 휠을 굴려 좌우로 스크롤**할 수 있고, 끄는 도중 좌우 끝으로 가면 저절로 따라 스크롤됩니다.
- **작은 버튼의 2단은 직접 정합니다** — 작은 버튼은 기본적으로 **각자 한 칸**을 쓰고(윗줄), 다른 작은 버튼의 **바로 아래로 끌어다 놓으면** 그 칸의 아래 줄에 들어가 2단이 됩니다. 저절로 두 개씩 묶이지 않으므로 **어떤 버튼끼리 한 칸을 쓸지 직접 고를 수 있고**, 아래 줄을 비워 둔 채 윗줄만 쓰는 것도 됩니다(한 칸에는 최대 두 개까지). 예전 버전에서 쌓여 있던 배치는 업데이트해도 그대로 유지됩니다.
- **목록은 종류별로 묶여 있습니다** — 필터는 필터끼리, 색상은 색상끼리 한 덩어리로 모입니다. 머리글의 **연결고리 버튼**을 누르면 그 종류만 고리가 풀려 버튼을 하나씩 자유롭게 옮길 수 있고(다른 종류 사이에 끼워 둘 수도 있습니다), 다시 누르면 한 덩어리로 모입니다. 고리가 걸린 종류는 미리보기에서 그 종류의 버튼 하나를 덩어리 **밖으로** 끌면 그 종류 전체가 통째로 따라가고, 덩어리 **안에서** 끌면 그 안에서만 순서가 바뀝니다. 고리 상태도 설정과 함께 저장됩니다.
- **버튼 추가**는 "+ 버튼 추가"를 누르면 종류 카드가 펼쳐지고, 카드마다 그 버튼이 무슨 일을 하는지 한 줄 설명이 붙어 있어 고르는 순간 바로 알 수 있습니다. 카드는 **기본**(뷰템플릿·필터·작업세트·색상·기능, 큰 카드)과 **링크**(링크된 요소·링크된 도면만·링크된 모델만, 한 줄짜리 작은 카드) 두 섹션으로 나뉘어 있습니다.
- 설정 창에서 뷰템플릿/필터/작업세트/카테고리/기능 대상을 고를 때 목록 위의 검색칸에 이름을 입력해 필터링할 수 있고, 옆에 "선택됨 N개"와 "전체 해제"가 함께 표시됩니다.
- 내보내기/가져오기와 툴바 위치 초기화는 창 아래 "고급 설정"을 펼치면 나옵니다.
- 버튼마다 **아이콘 모양·색상·크기**를 직접 지정할 수 있습니다. 켜고 끄는 버튼은 켜졌을 때 버튼 배경 전체가 지정한 색으로 채워지고(기본 초록), **켜고 끄는 개념이 없는 실행형 버튼(색상·기능·층별 단면상자)은 평소에도 늘 칠해져 있습니다**(기본 스틸블루 — 켜짐 색과 구분되도록 다른 색을 기본으로 씁니다). 아이콘과 글자는 그 배경색에 대비되는 색으로 자동 전환됩니다. 크기는 **큰 버튼**(아이콘 + 이름)과 **작은 버튼**(아이콘만 옆에 두 줄까지의 이름) 중에서 고릅니다. 작은 버튼은 높이가 큰 버튼의 절반으로 고정되어 **이름 길이에 상관없이** 한 칸에 두 개까지 위아래로 놓을 수 있고(이름이 길면 두 줄까지 보이고 나머지는 …으로 줄어듭니다 — 전체 이름은 버튼에 마우스를 올리면 나옵니다), 어떤 버튼끼리 한 칸을 쓸지는 위 "작은 버튼의 2단" 설명대로 직접 정합니다.
- 다른 뷰로 전환하면 그 뷰의 실제 상태에 맞춰 자동으로 갱신됩니다. 툴바 왼쪽 끝 손잡이를 드래그해 위치를 옮길 수 있고, 이 위치는 PC 전역으로 저장되어 어떤 프로젝트 파일을 열어도 그대로 유지됩니다.
- **설정은 이 PC에 하나로 저장됩니다** — 어떤 프로젝트를 열어도 등록해 둔 버튼이 그대로 따라옵니다(예전에는 프로젝트 파일마다 따로 저장했습니다). 대상(뷰템플릿·필터·작업세트)은 저장된 내부 ID가 아니라 **이름**으로 열려 있는 프로젝트에서 다시 찾으므로, 같은 이름의 뷰템플릿/필터/작업세트를 쓰는 프로젝트라면 어디서든 그대로 동작합니다. 그 이름이 없는 프로젝트에서는 그 버튼만 회색으로 표시되고(설정 창에는 "이 프로젝트에 없음"으로 나옵니다) 다른 버튼은 정상 동작합니다. 처음 이 버전을 실행하면 지금 열려 있는 프로젝트의 기존 설정을 그대로 이어받습니다.
- 리본의 "표시/숨김" 버튼으로 툴바 자체를 껐다 켤 수 있습니다. 설정 창의 "고급 설정"에 있는 "버튼모음 내보내기"/"버튼모음 가져오기"로 등록해 둔 버튼들을 파일 하나로 저장했다가 다른 PC에서 그대로 불러올 수 있습니다(가져온 버튼은 기존 버튼을 지우지 않고 뒤에 추가됩니다).
- 툴바 우측 끝에는 **설정(톱니바퀴) 버튼**이 항상 붙어 있어, 리본까지 가지 않고 여기서 바로 커스텀 버튼 설정 창을 열 수 있습니다.

### 경고Pick
현재 문서의 경고(Manage 탭의 "경고 검토"와 같은 `Document.GetWarnings()`)에 걸린 요소를 모아 보여주고, 골라서 바로 선택까지 해 줍니다.
- Revit 기본 경고창은 클릭 시 요소를 뷰로 안내(하이라이트)만 할 뿐 실제로 선택해 주지는 않아 직접 찾아 클릭해야 하는데, 경고Pick은 행의 "선택" 버튼 한 번으로 그 요소가 있는 뷰로 이동하면서 동시에 선택 상태가 됩니다.
- 경고를 **종류 → 발생 건 → 관련 요소** 3단으로 묶어 보여줍니다. 같은 종류의 경고(예: "벽이 겹칩니다")가 여러 쌍에서 따로따로 발생해도 한 종류 아래에 모이고, 그 안에서 실제 발생 건(예: 벽 A-B, 벽 B-C)과 거기 얽힌 요소가 몇 개든 전부 펼쳐 보여줍니다("어떤 요소와 어떤 요소가 만나서 문제가 생겼는지" 한눈에 확인). 요소 목록은 기본적으로 접혀 있고 발생 건의 "▸"를 눌러야 펼쳐집니다.
- 요소 행을 클릭하면 체크, 클릭한 채로 드래그하면 지나가는 여러 요소가 한 번에 체크/해제되고, 쉬프트를 누른 채 다른 요소를 클릭하면 그 사이 범위가 전부 체크됩니다(탐색기 다중 선택과 같은 방식). "체크한 요소 선택"을 누르면 체크된 요소들이 한 번에 같이 선택됩니다. 경고/발생 건 제목의 체크박스를 누르면 그 아래 요소를 한꺼번에 체크/해제할 수 있고, "전체 선택"/"전체 해제"로 화면에 보이는 모든 체크박스(종류·발생 건·요소 전부)를 한 번에 맞출 수 있습니다.
- "체크한 요소 단면상자로 보기"는 체크된 요소를 감싸는 단면상자를 3D 뷰에 만듭니다(3D 뷰가 활성화되어 있어야 합니다). "체크한 요소만 표시"는 그 요소만 남기고 나머지를 임시로 숨기며(Revit의 임시 격리), "격리 해제"로 되돌릴 수 있습니다.
- **경고 목록은 실시간으로 따라 바뀝니다** — 창을 열어 둔 채 모델을 고쳐 경고가 사라지거나 새로 생기면, "새로고침"을 누르지 않아도 목록이 저절로 갱신됩니다(모델이 실제로 바뀔 때만 확인하므로 평소 작업이 느려지지 않습니다). 갱신되어도 체크해 둔 요소, 펼쳐 둔 발생 건, 스크롤 위치는 그대로 유지되며, 경고가 하나도 안 바뀌었으면 화면을 건드리지 않습니다. "새로고침" 버튼은 그대로 남아 있어 언제든 직접 다시 읽을 수 있습니다.
- 창을 닫지 않고 열어 둔 채로 모델을 계속 조작(수정·삭제 등으로 경고 해결)할 수 있는 모드리스 창이며, "새로고침" 버튼으로 최신 경고 상태를 다시 불러올 수 있습니다.
- 경고를 조회했던 문서와 다른 문서가 활성화된 상태에서 선택을 시도하면(창을 열어 둔 채 다른 프로젝트로 전환한 경우) 안내 후 선택을 거부합니다.


### 룸 구분선
고른 벽 유형의 벽을 찾아 그 벽의 **중심선** 위에 룸 구분선을 자동으로 만듭니다. 방을 나누는 기준이 되는 벽(예: 세대 경계벽, 방화벽)을 유형으로 한 번만 고르면, 그 벽들을 따라 구분선이 한꺼번에 생깁니다.
- **링크된 모델의 벽도 대상입니다.** 링크는 레벨 이름이 달라도 됩니다 — 링크의 레벨 높이를 이 모델 좌표로 환산해 같은 높이(±300mm)의 레벨로 맞춥니다. 만들어지는 구분선은 언제나 이 모델에 생깁니다(링크 모델은 건드리지 않습니다).
- **벽의 위치선이 중심선이 아니어도 실제 중심에 맞춥니다.** 벽의 실제 형상에서 양쪽 벽면을 재어 그 한가운데로 선을 옮기므로, 위치선이 "마감면: 외부"나 "코어면"으로 설정된 벽에서도 구분선이 벽 한가운데에 놓입니다(곡선 벽처럼 벽면을 잴 수 없는 경우에는 위치선 그대로 그리고, 그런 벽이 몇 개였는지 결과 창에서 알려 줍니다).
- **벽처럼 모서리에서 서로 연결됩니다.** 방향이 다른 두 벽이 만나는 곳에서는 구분선도 교점까지 연장하거나 잘라내 실제로 맞닿게 하고, **가로지르는 벽에 쪼개져 있던 같은 선상의 구분선들은 한 줄로 이어 붙입니다**(문처럼 확실히 떨어져 있는 곳은 그대로 둡니다). 호(곡선) 벽은 원래 곡선 그대로 그립니다.
- **레벨을 여러 개 골라 한 번에** 만들 수 있습니다. 창을 열면 지금 보고 있는 평면뷰의 레벨이 미리 체크되어 있습니다. 룸 구분선은 평면뷰에서만 만들 수 있으므로, 평면뷰가 없는 레벨은 건너뛰고 결과 창에 알려줍니다.
- 벽 유형 목록은 이 모델과 링크의 벽을 모두 훑어 만들며, 같은 이름의 유형은 한 줄로 합쳐 "이 모델 · 링크 N개 · 벽 N개"처럼 어디에 몇 개가 있는지 보여줍니다. 검색칸으로 이름을 걸러낼 수 있습니다.
- **이미 있는 구분선은 지우지 않고 새로 추가합니다.** 같은 조건으로 여러 번 실행하면 같은 자리에 선이 겹쳐 쌓이니, 되돌리려면 Revit의 실행 취소(Ctrl+Z)를 쓰세요(한 번의 실행이 트랜잭션 하나라 한 번에 되돌아갑니다).

### 룸 경계 ON/OFF
벽·바닥·지붕·기초처럼 방의 경계를 만드는 요소들의 **룸 경계(Room Bounding)** 속성을 **카테고리 단위로 한 번에** 켜고 끕니다.
- **카테고리 목록은 모델을 훑어 만듭니다** — 룸 경계 속성을 실제로 가진 카테고리만 나오므로 벽·바닥·지붕·기초는 물론 천장·기둥·커튼시스템·매스처럼 그 속성이 있는 것은 무엇이든 함께 나옵니다(Revit 버전에 따라 늘어나는 카테고리도 그대로).
- 카테고리마다 **지금 몇 개가 켜져 있고 몇 개가 꺼져 있는지** 보여주며, "켜짐 0"인 카테고리는 눈에 띄게 표시합니다 — "왜 방이 안 나뉘지?"의 원인이 대개 이것입니다.
- **RVT 링크도 목록에 나옵니다.** 그 링크가 이 모델의 방 경계를 만드는지를 링크 단위로 끄고 켤 수 있습니다(링크 안의 요소를 바꾸는 것이 아니라 링크 인스턴스의 속성입니다).
- 요소에서 룸 경계 속성이 읽기 전용이면 "변경 불가"로 세어 보여주고 건드리지 않습니다. 이미 원하는 상태인 요소는 그대로 둡니다.
- 한 번의 실행은 트랜잭션 하나라 **Ctrl+Z로 한 번에 되돌릴 수 있습니다.** 다만 룸 경계를 끄면 방이 합쳐지거나 면적이 달라지고 방 면적을 쓰는 일람표·태그도 함께 바뀐다는 점에 유의하세요.
### 매개변수 조합 (여러 매개변수를 합쳐 자동 기입)
여러 매개변수의 값을 정해진 자리수로 채워 하나로 합친 뒤, 결과 매개변수에 **실제 값으로** 써넣습니다. 예: 룸의 `용도 + 지상지하 + 층 + 번호` → `실번호 = XX01003`.
- 일람표의 "결합된 매개변수"는 일람표에서만 보이는 표시값이지만, 여기서 만드는 값은 **요소 자체에 저장되는 진짜 데이터**라 태그·다른 일람표·내보내기에서 그대로 쓸 수 있습니다.
- **값이 바뀌면 즉시 따라 바뀝니다.** 번호를 `001 → 002`로 고치는 순간 실번호도 같이 바뀝니다. 같은 일을 Dynamo로 하면 값을 고칠 때마다 그래프를 다시 Run해야 하는데, 이 도구는 Revit이 그 변경을 처리하는 바로 그 순간에 끼어들어 계산하므로 **버튼을 누를 필요가 없습니다**(Ctrl+Z 한 번이면 소스 값과 결과 값이 함께 되돌아갑니다).
- **자리수를 맞춰 0을 채웁니다.** 층/번호가 숫자 매개변수면 Revit 내부에는 `1`, `3`으로 저장돼 있어 그냥 이어붙이면 `XX13`이 되는데, 매개변수마다 자리수·채움 문자·채울 위치(앞/뒤)를 정해 `XX01003`처럼 만들 수 있습니다.
- **룸 전용이 아닙니다.** 대상 카테고리를 고르고, 합칠 매개변수를 원하는 개수만큼 순서대로 추가하고, 결과를 쓸 매개변수를 지정하는 방식이라 문·창·가구 등 어디에나 같은 방식으로 쓸 수 있습니다. 규칙은 여러 개 만들어 두고 각각 켜고 끌 수 있습니다.
- **저장 전에 결과를 미리 봅니다.** 지금 모델에 적용하면 어떤 요소가 어떤 값으로 바뀌는지(현재값 → 적용 후) 목록으로 보여주고, 바뀌는 개수·건너뛰는 개수·이유를 함께 알려줍니다.
- 리본의 **실시간 켜짐/꺼짐** 토글로 자동 반영만 껐다 켤 수 있고(규칙은 그대로 남습니다), **전체 갱신** 버튼으로 기존 요소 전체를 한 번에 맞출 수 있습니다.
- 결과 매개변수는 그 요소의 **인스턴스·문자 형식** 매개변수여야 합니다. 없으면 경고만 하고 아무것도 바꾸지 않습니다 — 회사 표준 공유 매개변수 파일을 애드인이 대신 고치지 않기 위해서입니다(Revit에서 먼저 만들어 카테고리에 붙여주세요).

### 일괄 결합금지/허용 (부재 끝 결합)
벽·보·가새의 **끝**이 맞닿은 부재와 결합되는 것(Revit의 "결합 허용 안 함")을 한 번에 걸거나 풉니다. Revit 기본 UI에서는 부재 하나의 끝 하나씩만 오른쪽 클릭으로 걸 수 있어, 벽이 수백 개인 모델에서는 사실상 손으로 못 하는 작업입니다.
- **선택한 부재 전부**에 걸거나, **유형을 골라 그 유형의 모든 인스턴스**에 걸 수 있습니다. 리본의 작은 `선택 금지`/`선택 허용` 버튼은 창을 열지 않고 지금 선택한 요소의 양쪽 끝을 바로 처리합니다.
- **양쪽 끝 / 시작점 쪽 / 끝점 쪽**을 골라 적용할 수 있습니다(기본값은 양쪽 끝).
- 유형마다 **지금 몇 곳이 금지이고 몇 곳이 허용인지** 보여주고, 전부 금지인 유형은 눈에 띄게 표시합니다. "현재 뷰에 보이는 요소만"으로 범위를 좁힐 수도 있습니다.
- 대상은 **벽과 구조 프레임(보·가새)**입니다 — Revit에 끝단 결합 설정이 있는 것이 이 둘뿐입니다. 스택 벽의 하위 벽처럼 Revit이 거부하는 것은 "바꾸지 못한 끝"으로 세어 알려주고, 이미 원하는 상태인 끝은 그대로 둡니다.
- 한 번의 실행은 트랜잭션 하나라 **Ctrl+Z로 한 번에 되돌릴 수 있습니다.**

### 화면 디자인
모든 도구 창은 하나의 디자인 시스템을 공유합니다 — 밝은 배경에 스틸블루 강조색, 사각형(무라운드) 모서리, 얇은 실선 테두리의 설계도면(blueprint) 스타일이며, 주요 액션 버튼만 강조색으로 채워진 유일한 입체 요소입니다. 리본 버튼 아이콘도 같은 언어를 씁니다 — 전부 실행 시점에 코드로 그리며(PNG 이미지를 쓰지 않습니다), 밝은 면에 얇은 먹선을 두르고 그 버튼이 실제로 하는 일(자르는 선, 합쳐진 결과, 켜진 상태, 뚫린 구멍)에만 강조색을 씁니다. 16px 작은 버튼에서도 읽히도록 같은 도형을 크기에 맞춰 다시 계산해 그립니다. 리본 탭/패널 자체의 배경·테두리는 Revit이 그리는 네이티브 UI라 이 도구가 바꿀 수 없고, 바꿀 수 있는 건 버튼 아이콘 이미지와 이 도구가 만든 창들의 내부뿐입니다.

## 설치 (사용자용)

1. 저장소 루트의 `SunnyTools_Installer_v.0.9.0.zip`(버전이 붙은 최신 zip 하나만 루트에 있습니다)을 내려받아 압축을 풉니다.
2. 실행 중인 Revit을 모두 종료한 뒤 `SunnyTools_Install.exe`를 실행합니다. 설치된 Revit 버전을 자동으로 감지해 해당 버전에 맞는 파일과 `.addin` 매니페스트를 설치합니다.
3. Revit을 실행하면 리본에 "Sunny Tools" 탭이 나타납니다.

## 개발 / 빌드

.NET SDK가 설치되어 있어야 합니다.

```powershell
# 애드인만 특정 연도로 빌드
dotnet build WallSplitter/WallSplitter.csproj -c Release2026

# 설치 프로그램 빌드 (5개 연도 전체를 자동으로 빌드해 포함)
dotnet publish SunnyToolsInstaller/SunnyToolsInstaller.csproj -c Release
```

같은 소스를 `Debug2023`~`Release2027` 10개 Configuration으로 빌드하며, 각 Configuration의 4자리 연도가 `$(RevitVersion)`으로 읽혀 대상 프레임워크와 `Nice3point.Revit.Api.RevitAPI`/`RevitAPIUI` 패키지 버전을 결정합니다.

## 알려진 제한사항

- 원본 벽/바닥에 호스팅된 문/창은 재호스팅되지 않고 원본과 함께 삭제됩니다.
- 코너 자동 트림은 직선(Line) 기반 벽 쌍만 지원하며, 호(Arc) 코너는 미지원입니다.
- 두께는 mm 단위 반올림 표시되어, 소수점 차이가 있는 레이어는 같은 유형으로 병합될 수 있습니다.
- 재료/유형 사용처 재지정은 `ElementType` 단위까지만 스캔하며, 인스턴스별 재료 오버라이드는 대상이 아닙니다.
- 모델간 변경 반영은 이름 기반 매칭이라, 서로 다른 패밀리에 같은 이름의 유형이 있으면 혼동될 수 있습니다 (직접 고르는 창에서 패밀리명도 함께 표시).
- 모델간 변경 반영의 변경 기록(change-log.json)은 자동으로 정리되지 않고 계속 쌓이며, 창에서 수동으로만 삭제할 수 있습니다.
- 모델선 패턴 캡처는 CAD 링크의 선을 직접 읽지 않습니다. CAD 링크를 배경으로 두고 Revit 모델선 또는 상세선으로 따라 그린 뒤 ㄱ자 세 점 반복 틀을 지정하는 방식이며, 빈 화면 자유 드로잉 편집기는 후속 범위입니다.
- 패턴 타공은 대상 면 전체와 표면 패턴이 현재 2D 뷰의 자르기 영역 안에 보여야 합니다. 시스템 커튼월 패널은 Revit이 원본 패밀리 편집을 허용하지 않으므로 직접 타공하지 않으며, 로드 가능한 커튼패널 유형으로 교체한 경우에 지원합니다.
- 적용된 면 하나의 패턴 위치·각도만 다시 맞추는 기능은 아직 포함되지 않습니다.
- 커스텀 버튼 툴바는 Revit 메인 창에만 붙으며, 뷰를 별도 창으로 분리하면 그 창은 따라가지 않습니다. 커스텀 버튼의 대상은 이름으로 다시 찾으므로, 프로젝트마다 뷰템플릿/필터/작업세트의 이름이 다르면 그 프로젝트에서는 해당 버튼이 회색으로 표시됩니다.
- 매개변수 조합은 이 문서 안의 요소만 봅니다 — 링크 모델에 있는 값을 소스로 쓸 수 없습니다. 작업공유 모델에서 다른 사용자가 소유한 요소에는 쓰지 못하고 결과에 개수로 알려줍니다. 설정은 PC 전역이라 프로젝트마다 다른 규칙을 둘 수 없습니다.
- 일괄 결합금지/허용의 대상은 벽·보·가새뿐입니다 — Revit에 끝단 결합 설정이 있는 것이 이 둘뿐이라, 기초·바닥·지붕에는 이 설정 자체가 없습니다. 링크 모델의 요소는 바꿀 수 없고, 작업공유 모델에서 다른 사용자가 소유한 요소는 "바꾸지 못한 끝"으로 세어 알려줍니다.
- 경고Pick은 현재 선택만 가능하며, 경고 자체를 자동으로 해결하거나 지우는 기능은 아직 없습니다(Revit API 제약상 일반적인 자동 해결이 어려운 이유는 `docs/warning-pick/CLAUDE.md` 참고).

더 자세한 설계 배경과 이력은 `CLAUDE.md`(절대 규칙 + 작업 영역별 문서 라우팅)와 `docs/<영역>/CLAUDE.md`(기능별 상세 이력)를 참고하세요.
