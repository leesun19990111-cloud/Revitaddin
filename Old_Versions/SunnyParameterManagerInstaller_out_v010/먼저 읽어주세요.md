# Sunny 매개변수 관리자 0.1.0 — 첫 테스트 버전

Sunny Tools 리본과 별도로 실행하는 Windows 프로그램입니다. 엑셀 규칙 적용은 아직 없습니다.

## 설치 및 첫 실행

1. 열린 작업을 저장하고 Revit과 매개변수 관리자를 모두 종료합니다.
2. `SunnyParameterManager_Installer_v.0.1.0.zip` 전체를 풀고 `SunnyTools_Install.exe`를 실행합니다. 옆의 `ParameterManager` 폴더를 지우지 마세요.
3. 바탕화면의 **Sunny 매개변수 관리자**를 실행합니다.
4. **샘플로 둘러보기**에서는 파일을 열지 않고 검색·직접 입력·변경 예정 목록을 시험할 수 있습니다. 샘플의 실제 적용은 차단됩니다.

필수: Windows x64, 설치·인증된 Revit 2026, .NET 8 Desktop Runtime x64. Revit 2026.4 API 기준으로 빌드했습니다. 다른 Revit 연도, Revit Server/ACC 클라우드 경로, 자동 업그레이드, 분리 모델은 이 버전에서 지원하지 않습니다. 일반 파일 경로·공유폴더/UNC의 RVT만 지원합니다.

설치기는 기존 Sunny Tools를 바꾸지 않고 별도 연결 모듈만 등록합니다. .NET 런타임이 없으면 [Microsoft 공식 다운로드](https://dotnet.microsoft.com/download/dotnet/8.0)의 **.NET Desktop Runtime / Windows x64**를 설치하세요.

## 실제 모델 편집

1. 운영 중앙이 아닌 **별도 테스트 모델**을 준비하고 **RVT 추가**로 등록합니다. 연결된 모델의 값도 수정하려면 그 모델의 원본 RVT를 각각 추가합니다. 링크 내부를 자동으로 훑지는 않습니다.
2. **Revit 연결**을 누릅니다. 별도의 작업용 Revit이 시작됩니다. 로그인·애드인 허용 창이 뜨면 확인하세요. 대상 RVT를 사용자가 미리 열 필요는 없습니다. Revit 없이 파일을 직접 고치는 프로그램은 아닙니다.
3. **등록 모델 조회 / 새로고침**을 누릅니다. 유형·인스턴스·프로젝트 정보 범위와 매개변수를 선택합니다. 모델·유형·현재 값을 검색할 수 있습니다.
4. Ctrl/Shift로 여러 행을 선택하거나 **보이는 편집 가능 행 선택**을 누릅니다. 값을 입력하고 **변경 예정에 추가**를 누릅니다. 열 머리글로 정렬하고 열 경계로 너비를 조절할 수 있습니다.
5. **변경 예정 / 최종 적용**에서 기존 값·변경값·소속 모델을 확인합니다. 목록에 남은 항목은 검색/선택을 바꾸어도 유지됩니다. 원치 않는 변경은 **선택 변경 제외**로 제거하세요.
6. **최종 적용 · 저장 / 중앙 동기화**를 누르고 확인창에서 승인합니다. 모델별로 순차 처리합니다. 처리 결과 탭에서 성공 여부와 복구 경로를 확인하세요.

중앙파일을 선택하면 전용 작업용 로컬을 만들어 수정·동기화합니다. 기존 로컬을 선택하면 **그 로컬에 저장된 다른 미동기화 변경도 함께 동기화**됩니다. 다른 사람의 로컬은 열지 않습니다. 가급적 원래 중앙파일을 등록하세요. 다른 사용자의 로컬파일이 자동으로 덮어써지는 것은 아니며, 각 사용자가 최신 내용 가져오기를 해야 합니다.

작업용 Revit 창에 별도로 파일을 열지 마세요. 다른 Revit에서 동일 파일을 저장하거나 모델을 동시에 편집 중이면 충돌·소유권 때문에 실패할 수 있습니다. 다른 사용자의 소유권을 강제로 빼앗지 않습니다. 조회/적용이 끝나면 **작업용 Revit 종료**로 빈 전용 프로세스에 종료를 요청할 수 있습니다. 관리자를 닫아도 Revit을 강제 종료하지 않습니다.

## 모델 간 값 복사

- 왼쪽에서 조회한 **기준 모델**을 지정합니다. 값을 받을 다른 모델의 행을 선택하고 **선택한 행에 기준값 복사**를 누릅니다.
- 카테고리·패밀리·유형 이름이 정확히 같은 유형끼리 연결합니다. 공유 매개변수는 GUID, 기본 매개변수는 기본 식별자로 연결합니다.
- 공유 GUID가 없는 일반 매개변수는 **일반 매개변수 연결 승인**을 체크한 경우에만 같은 이름·자료형·범위의 유일한 후보에 연결합니다. 이름이 같아도 공유 GUID가 다르면 연결하지 않습니다.
- 인스턴스는 유형명이 같다고 같은 요소로 추정하지 않습니다. 인스턴스 값은 직접 여러 행 선택 후 일괄 입력하세요.
- 기준 모델의 **조회한 현재 값**을 복사합니다. 기준 모델에 아직 적용하지 않은 변경 예정 값은 복사하지 않습니다.

## 지원하는 편집 / 제한

- 텍스트, 사용자 정수, 숫자, 단위 숫자, 예/아니요, 재료 참조, 사용자 작업세트 선택. `재료명`, `업체명`, `층`, 공사코드 등은 실제 매개변수 자료형에 맞게 처리합니다.
- 텍스트를 비워 추가하면 실제 텍스트를 지웁니다. 숫자·선택 항목은 빈 값으로 지우지 않습니다. 숫자는 점 소수점, 치수는 `200 mm`처럼 단위까지 입력하는 것을 권장합니다.
- 다음으로 IFC로 내보내기 같은 텍스트는 입력할 수 있지만 IFC 스키마의 유효성이나 최종 IFC 파일은 이 프로그램이 검증하지 않습니다.
- 수식·실제 읽기 전용·아직 지원하지 않는 참조/열거값은 사유를 표시하고 수정하지 않습니다. 매개변수 생성·바인딩·형상 추가는 하지 않습니다.
- 뷰/시트, 일람표 행 대응, 엑셀 가져오기, 자동 유형 규칙, 예약 실행은 첫 버전 범위가 아닙니다.

## 안전과 복구

조회만으로 RVT에 값을 저장하지 않습니다. 실제 적용 직전에 문서 식별자, 요소, 매개변수, 기존 원시값, 자료형·단위·권한을 다시 확인합니다. 달라졌으면 덮어쓰지 않습니다. 일반파일/기존 로컬은 변경 전 파일 백업을 만듭니다. 중앙파일은 새 작업용 로컬을 보존하지만 이것은 중앙 서버 백업을 대체하지 않습니다.

여러 모델 전체를 한 번에 되돌리는 트랜잭션은 없습니다. 앞 모델이 성공하고 뒤 모델이 실패하면 앞 모델 변경은 남습니다. 저장/동기화 실패나 응답 손실은 자동 재시도하지 않습니다. **반영 여부 확인 필요**가 나오면 작업용 Revit과 로컬을 그대로 두고 처리 기록 및 실제 중앙 값을 먼저 확인하세요. 소유권은 자동으로 일괄 반납하지 않으므로 작업 후 필요한 소유권 반납도 확인하세요.

**작업 저장**은 조회값과 변경 예정 목록을 `.spm.json` 파일로 보관합니다. 이 파일 및 `%LOCALAPPDATA%\SunnyTools\ParameterManager\Sessions` 기록에는 모델 경로·매개변수 값이 포함되므로 외부 공유에 주의하세요. 로컬과 백업도 같은 기록 폴더에 남고 자동 삭제하지 않습니다. 중앙 반영·복구 확인 후 사용자가 필요 없는 기록을 정리할 수 있습니다.

이 버전은 빌드, 55개 값/화면 검사, 25개 API 대역 실패 분기를 검사했습니다. **실제 사용자 RVT 열기·저장·중앙 동기화는 아직 검증하지 않았습니다.** 네이티브 Revit 오류가 발생하지 않는다고 보증하지 않으며 운영 모델 전체에 바로 적용하지 마세요.
